## [v1.0](https://github.com/joa-no/Seoga/releases/tag/v1.0) — 2026-11-14

Initial public Android release of **Seoga**, an offline-first library manager for manga, manhwa, manhua, and comics.

### Highlights

- Manage a personal catalog with covers, metadata, reading progress, chapter tracking, and decimal ratings.
- Organize works into custom collections, including support for multiple collections per title.
- Add entries manually or look up metadata using MangaDex and AniList.
- Manage multiple catalog entries at once.
- Export and restore library data as ZIP backups.
- Use the app in English, Brazilian Portuguese, or Spanish.
- Keep library data on-device and use the core catalog without signing in.

**Please note:** Seoga is a catalog, not a manga or comics reader. It does not download or display comic pages. Online metadata lookup requires internet access.
